# VYBE
A responsive music library and player built with HTML, CSS and vanilla JavaScript.

## Features
- Add and play audio files selected from your device
- Search your collection and browse recently added tracks
- Create playlist names and mark favourites
- Shuffle, repeat, previous/next, volume and seek controls
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a modern browser. For best results, use a local development server.

## Deploy with GitHub Pages
1. Create a public repository named `VYBE`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After deployment, your site will be at `https://YOUR-USERNAME.github.io/VYBE/`.

## Audio and privacy
VYBE plays audio files selected on the device. Audio is not uploaded to a server. Audio files must be selected again after a refresh. Use music you own or have permission to play.
